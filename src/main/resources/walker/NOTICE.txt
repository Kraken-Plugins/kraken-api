The files in this directory, and the search code that reads them, come from the shortest-path
project by Skretzo and its contributors: https://github.com/Skretzo/shortest-path

  collision-map.zip   copied unchanged from that project
  dataset.json        converted from its transport files (src/main/resources/transports/*.tsv,
                      item-variations.tsv and spirit-tree-patches.tsv) by
                      scripts/update_walker_transports.py in the Kraken API repository
  transports.json     written for Kraken API, with item requirements taken from the same files

The classes of com.kraken.api.service.pathfinding that read the collision map and hold the nodes
of a search (WorldCollisionData, CollisionMap, NodeGraph, VisitedTiles, IntDeque, IntMinHeap) and the
wilderness areas in com.kraken.api.service.walker.transport.WildernessLevels are adapted from the
same project.

The line of dataset.json named "source" records the commit the data was taken at.
