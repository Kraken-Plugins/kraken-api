# MINOTAUR

[Kraken API]\
[MINOTAUR](index.md)

Minotaur: melee reinforcement. When no player is in melee reach on its attack timer it scans for a damaged NPC (below 75% max HP, centre within 7 tiles, line of sight, not a minotaur) and heals it instead. Its melee damage is applied one tick after the attack.
