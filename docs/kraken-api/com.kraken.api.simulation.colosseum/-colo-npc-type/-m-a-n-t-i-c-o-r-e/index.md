# MANTICORE

[Kraken API]\
[MANTICORE](index.md)

Manticore: charges a triple attack (10 ticks) on first line of sight, then fires three orbs on consecutive ticks - ranged/magic in a fixed per-spawn order, melee always last (Mantimayhem III unlocks melee-first patterns). Only one manticore may begin firing per tick; other ready manticores are delayed 5 ticks. Prayer is checked on each orb's launch tick (projectiles have no travel time).
