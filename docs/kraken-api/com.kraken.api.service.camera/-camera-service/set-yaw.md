# setYaw

[Kraken API]\
open fun [setYaw](set-yaw.md)(yaw: [Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-int/index.html))

Sets the camera yaw (compass facing direction). 

 Yaw values: 

- North = 0, 2048
- East = 1536
- South = 1024
- West = 512

#### Parameters

Kraken API

| | |
|---|---|
| yaw | the target yaw value (must be between 0 and 2047) |
