[Kraken API]\
open fun [adjustPitch](adjust-pitch.md)(percentage: [Float](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-float/index.html))

Adjusts the camera pitch to the specified percentage. Uses keyboard input to smoothly transition to the target pitch.

#### Parameters

Kraken API

| | |
|---|---|
| percentage | the target pitch as a percentage (0.0 to 1.0, where 0 is looking down and 1 is looking up) |
