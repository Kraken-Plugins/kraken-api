# worlds

[Kraken API]\
open fun [worlds](worlds.md)(): [WorldQuery](../../com.kraken.api.query.world/-world-query/index.md)

Creates a new query builder for Worlds. A WorldQuery provides functionality for filtering and selecting specific game worlds based on various criteria, such as population, world type, or location. 

Worlds are the game servers that players can connect to. Each world may have unique properties, such as member status, high population, or special game rules.

#### Return

@WorldQuery object used to chain together predicates to select specific game worlds.
