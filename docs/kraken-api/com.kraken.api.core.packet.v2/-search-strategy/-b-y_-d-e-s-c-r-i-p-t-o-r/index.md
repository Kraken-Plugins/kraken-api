# BY_DESCRIPTOR

[Kraken API]\
[BY_DESCRIPTOR](index.md)

Match fields whose descriptor exactly equals searchName. Useful for unnamed fields with a distinctive primitive or array descriptor. Use ownerName to narrow to a specific class — strongly recommended here since primitive descriptors like &quot;J&quot; will appear across many classes.
