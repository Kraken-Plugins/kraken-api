# isEmpty

[Kraken API]\
open fun [isEmpty](is-empty.md)(): [Boolean](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-boolean/index.html)

Checks if the stream contains no elements. 

 This method determines whether the stream is empty by checking if the count of elements in the stream is equal to zero. 

#### Return

`true` if the stream contains no elements; otherwise, `false`.
