# isClosed

[Kraken API]\
open fun [isClosed](is-closed.md)(): [Boolean](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-boolean/index.html)

Determines whether the bank deposit box interface is currently closed. 

This method performs the inverse check of [isOpen](is-open.md) to determine if the deposit box interface is not visible to the user.

#### Return

`true` if the deposit box interface is closed; `false` otherwise.
