# wieldOrWear

[Kraken API]\
open fun [wieldOrWear](wield-or-wear.md)(): [Boolean](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-boolean/index.html)

Wields or wears an equippable item dependent on the item. If the items action contains &quot;wear,&quot; then the item will be worn, else it will be wielded/equipped.

#### Return

true if the item was equipped and false otherwise
