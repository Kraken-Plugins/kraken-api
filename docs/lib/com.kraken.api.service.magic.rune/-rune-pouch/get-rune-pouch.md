# getRunePouch

[Kraken API]\
open fun [getRunePouch](get-rune-pouch.md)(): [RunePouch](index.md)

Retrieves the `RunePouch` instance corresponding to a rune pouch currently present in the player's inventory. This checks all available rune pouch variants and returns the matching instance if any are found.

#### Return

The `RunePouch` corresponding to a pouch found in the player's inventory, or `null` if no matching pouch exists.
