# closeNumberDialogue

[Kraken API]\
open fun [closeNumberDialogue](close-number-dialogue.md)()

Runs a client script to close the numeric input dialogue if it is open. This dialogue is shown when players are prompted to enter a number like: inputting GE offers, clue scroll steps, or withdrawing-X items from the bank.
